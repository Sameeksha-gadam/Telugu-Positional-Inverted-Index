TELUGU POSITIONAL INVERTED INDEX IR Assignment 1

1.  Introduction

For this assignment, I implemented a positional inverted index using
Telugu Wikipedia articles. The purpose of this project is to store each
word along with the documents in which it appears and the positions
where it occurs.

The index also stores Document Frequency (DF) and Collection Frequency
(CF) for every term.

2.  Dataset Used

Language: Telugu Dataset: Telugu Wikipedia pages-articles dump File
name: tewiki-latest-pages-articles.xml.bz2 Source link:
https://dumps.wikimedia.org/tewiki/latest/tewiki-latest-pages-articles.xml.bz2

I extracted 500 Telugu Wikipedia articles from the dataset. Each article
is stored as a separate text file in the extracted_articles folder. The
article details are stored in metadata.csv.

The original Wikipedia dump is not included in this submission because
of its size. It can be downloaded using the source link above.

3.  Implementation

Article Extraction: The extract_articles.py program reads the compressed
Wikipedia XML file, selects articles, removes wiki markup and saves the
article text in separate files.

Preprocessing: The preprocessing.py program normalizes the text and
tokenizes Telugu text, English words and numbers. It also assigns
positions to the tokens in each document. Positions start from 1.

Index Construction: The indexer.py program reads the extracted documents
and creates the positional inverted index. For every term, it
calculates: - Document Frequency (DF): Number of documents containing
the term. - Collection Frequency (CF): Total number of occurrences of
the term in the collection. - Positions: The positions where the term
occurs in each document.

Index Storage: The storage.py program stores the vocabulary in
vocabulary.json and the positional postings in postings.txt. The
vocabulary contains the DF, CF and byte offset for each term. The
postings are stored separately on disk.

Searching: The search.py program accepts a Telugu word from the user and
searches for it in the index. It displays the DF, CF, document IDs and
positions of the term.

Test Output: The generate_output.py program creates five test cases
using ten rare Telugu terms. The results are saved in
output/test_results.txt.

5.  Required Package

This project uses Python 3 and the external package mwparserfromhell.

Install the package using:

    pip install mwparserfromhell

The other modules used in the programs are part of Python’s standard
library.

6.  How to Run

Run the following commands from the main IR_Assignment folder.

Step 1: Extract the articles:

    python src/extract_articles.py

Step 2: Build the positional index:

    python src/indexer.py

Step 3: Store the vocabulary and postings:

    python src/storage.py

Step 4: Search for a Telugu word:

    python src/search.py

Step 5: Generate the test results:

    python src/generate_output.py

Step 6: Verify the DF and CF values:

    python tests/test_index.py

Before running the extraction program, place
tewiki-latest-pages-articles.xml.bz2 inside the dataset folder.

7.  Results

The project was run with the following results:

Number of extracted documents: 500 Number of unique terms: 111577

For the search term భారతదేశం, the program displayed:

DF = 119 CF = 262

The verification program calculated the same DF and CF values.

The generated test_results.txt file contains five test cases and ten
rare Telugu terms. All ten terms showed PASS in the generated results.

8.  Notes

-   The positions in the index are token positions generated by the
    tokenizer.
-   The tokenizer uses Unicode character ranges for Telugu text and also
    handles English words and numbers.
-   Stopwords are retained.
-   The SQLite database is an intermediate index file. The search
    program uses vocabulary.json and postings.txt.

The dataset is from Telugu Wikipedia. Please refer to the source website
for its licensing and attribution information.
